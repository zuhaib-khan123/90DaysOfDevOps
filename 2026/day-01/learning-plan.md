# 90-Day Learning Plan

## Current Level
Student with beginner-level knowledge of programming and some tools. Currently learning DevOps fundamentals and improving practical skills.

## Goals for the Next 90 Days
1. Learn and use Git & GitHub confidently in real projects.
2. Build and deploy a simple application using Docker and Kubernetes.
3. Understand and create basic CI/CD pipelines using GitHub Actions or Jenkins.

## Core DevOps Skills to Build
1. Linux command line and troubleshooting
2. Docker and Kubernetes fundamentals
3. CI/CD pipeline setup and debugging

## Weekly Time Budget
- Weekdays: 2–2.5 hours daily
- Weekends: 3 hours daily
- Total: ~12-14 hours per week

## Learning Strategy
- Practice daily instead of studying occasionally for long hours
- Focus on hands-on learning and mini projects
- Revise concepts weekly and track progress consistently

## Expected Outcome
By the end of 90 days, I want to be comfortable working with basic DevOps tools, deploying applications, and understanding real-world development workflows and able to get a DevOps internship/job.
